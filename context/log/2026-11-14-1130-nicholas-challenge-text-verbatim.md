## Learned / gotchas
- Context.dev has two entries: a main challenge (prizes 2,000 / 500 euro) and a tech challenge (750 / 250 euro). The tech one requires a core-flow endpoint call, a GitHub repo, a demo and a short note on which endpoints were used.
- Nemotron's minimum requirements include a short text explanation in the submission form: model used, what it does, why it matters, how outputs were improved.
- Verda's minimum requirement is to document the process and post a summary link in their Discord channel.
- Junction lists only one S-Pankki challenge; the "S-Bank" material is the same challenge plus the dataset README.
