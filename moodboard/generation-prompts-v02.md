# Sisu v0.2 generation prompts

Date: 13 November 2026. Generated with the built-in imagegen tool. The five-view Liito sheet was used as the visual reference for the mood grid and hero. These are draft concepts for team selection, not an approved vector master. The cleanup prompts use their preceding generated image as the edit target. The exact prompt text retains the earlier working name Hillo; the kit was renamed to Sisu during this task. No product name is baked into the illustrations.

The current kit uses S green for the membrane and mint cheeks. The inherited grey, cream and eye ink are confined to Liito. Surrounding artwork and UI follow the current S-mobiili green palette.
